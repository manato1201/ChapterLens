# 用語集

## 検出・言葉

| 用語 | 意味 |
|---|---|
| **字幕(cue)** | 開始秒・終了秒・文の 3 つ組。字幕 1 行(`Cue`) |
| **分かち書き** | 文を「語」に分けること。日本語は文字の 2 つ組(bigram)で近似する |
| **bigram** | 隣り合う 2 文字の組。「機械学習」→ 機械・械学・学習 |
| **ストップワード** | どの話題にも出る、役に立たない語(the・and など)。数えない |
| **TF** | 語の出現回数(ここでは `1 + log 回数`) |
| **IDF** | 語の珍しさ。多くの区間に出る語ほど小さい(`log((n+1)/(df+1)) + 1`) |
| **TF-IDF** | TF × IDF。その区間で多く、他では少ない語ほど大きい重み |
| **コサイン類似度** | 2 つのベクトルの向きの近さ(0〜1)。量でなく構成比を見る |
| **ビン** | 時間を 10 秒ごとに区切った 1 つの入れ物。語を数える単位 |
| **類似度の曲線** | 各境界の前後の窓の類似度を並べたもの。谷が話題の切り替え |
| **平滑化** | 移動平均で、曲線のギザギザを丸めること |
| **谷の深さ(depth score)** | 左右の山との高さの差の合計。両側が高く、自分だけ低いほど大きい |
| **TextTiling** | 語の分布の変化で、文章を話題の区切りに分ける古典的な方法 |
| **snap(寄せる)** | 計算で出した境界を、近くの字幕の開始時刻に合わせること |
| **置き直し(refine)** | 境界の近くで、前後の類似度が最小になる位置へ動かすこと |
| **粒度** | 章の数の目安(粗い・標準・細かい)。個数を決めて深い順に選ぶ |
| **境界(boundary)** | 区間の切れ目の時刻(先頭の 0 秒を含まない) |
| **章(チャプター)** | 境界で区切った区間。先頭は 0 秒 |
| **信頼度(score)** | その境界の谷の深さ ÷ 最大の深さ(相対値) |

## 測る

| 用語 | 意味 |
|---|---|
| **適合率** | 検出したもののうち、本物だった割合(空振りの少なさ) |
| **再現率** | 本物のうち、見つけられた割合(取りこぼしの少なさ) |
| **F1** | 適合率と再現率の調和平均 |
| **許容(tol)** | 同じ境界とみなす時間の幅(±3 秒・±10 秒) |
| **基準(ベースライン)** | 何もしない方法(N 秒ごと・等間隔)。これを上回って初めて意味がある |
| **過学習** | 調整に使ったデータに合わせ込み、別のデータで精度が落ちること |
| **交差検証** | データを分け、使っていない部分で測ることを、入れ替えて繰り返す |
| **golden** | 正本(Python)の出力を保存した期待値。JavaScript が一致するか確かめる |
| **パーセンタイル** | 小さい順に並べて、何割目の値か(90 パーセンタイル = 悪い方の 1 割の境目) |

## 音声

| 用語 | 意味 |
|---|---|
| **PCM** | 音の波形を、一定の間隔で測った数の列 |
| **サンプリング周波数** | 1 秒に何回測るか(48 kHz → 16 kHz にして送る) |
| **ダウンサンプル** | サンプリング周波数を下げること(平均で) |
| **WAV** | PCM に 44 バイトのヘッダを付けた音声の形式 |
| **RMS** | 音の大きさの目安(二乗平均平方根)。無音の判定に使う |
| **チャンク** | 30 秒ごとの区切り |
| **ASR** | 音声認識。ここでは faster-whisper |
| **TimeMap** | 時計の時刻と動画の再生位置の対応表(一時停止・シーク・倍速を吸収) |
| **発話の頭** | 間(無音)の後に始まる単語の開始時刻。境界を寄せる先 |

## 拡張

| 用語 | 意味 |
|---|---|
| **Manifest V3** | Chrome 拡張の現行の仕様(service worker・offscreen を使う) |
| **content script** | ページの中で動く部品。ページの DOM を読む・画面を重ねる |
| **service worker(background)** | 拡張の裏の部品。必要なときだけ起動する。通信の中継 |
| **offscreen document** | 見えない HTML ページ。音の処理(`AudioContext`)を任せる |
| **popup** | アイコンを押したときの小さな画面。`tabCapture` はここから |
| **Shadow DOM** | ページの CSS と干渉しない、閉じた DOM の領域 |
| **UMD** | ブラウザ(`<script>`)でも Node(`require`)でも動く書き方 |
| **許可リスト** | 通してよいものを列挙して、それ以外を拒否する方式 |

## サーバー・安全

| 用語 | 意味 |
|---|---|
| **127.0.0.1 / ループバック** | 「この PC 自身」。外のネットワークから届かない |
| **token** | 本人を示す長い乱数(256 ビット)。保存するのはハッシュだけ |
| **ハッシュ(SHA-256)** | 元に戻せない一方向の変換 |
| **定数時間の比較** | 一致の位置で止まらない比較。応答時間から情報が漏れない |
| **Host / Origin** | 呼ばれた名前 / 呼んだページの出どころ。DNS リバインディングなどを防ぐ |
| **DNS リバインディング** | 悪いサイトの名前を、一時的に `127.0.0.1` に向けて、ローカルのサーバーを呼ぶ攻撃 |
| **レート制限(スライディング窓)** | 直近の一定時間に、何回まで呼べるか |
| **監査ログ** | 誰が・いつ・何をしたかの記録(内容は残さない) |
| **認可** | 「その操作をしてよいか」の判断。**サーバーで**行う |
| **XSS** | 入力に含まれる `<script>` などが、ページで実行されてしまう脆弱性 |
| **SQL インジェクション** | 入力が SQL の一部として解釈されてしまう脆弱性。`?` で値を渡して防ぐ |
| **S-A〜S-F** | 設計書の安全の基準線(認可・token・監査・入力検証・依存と CSP・分離) |

## 段階・方針

| 用語 | 意味 |
|---|---|
| **暫定(tentative)/ 確定(committed)** | ライブの 2 段。暫定は早く出る(間違いうる)、確定は後ろの文脈を見て決める |
| **取り下げ** | 暫定が、脱線だったと分かって消えること |
| **ダイジェスト** | 重要な区間だけを、再生中に自動で飛ばして見る。動画は切り出さない |
| **一致率(agreement)** | 自動の区間と、利用者が調整した区間の、時間の重なりの F1 |
| **EDL** | 編集の指示書(元のどこから、どこまでを、出力のどこへ) |
| **--own** | 書き出しで、自分の動画・許諾済みの素材であることを明示するフラグ |
| **R1〜R9 / R3** | 機能を増やさないための採用基準。R3 =「1 つ足すなら 1 つ外す」 |
| **CH0〜CH6** | 段階。測る土台 → 目次 → 音声 → 共有 → ダイジェスト → ライブ → 書き出し |
