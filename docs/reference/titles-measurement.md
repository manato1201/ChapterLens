状態: **未実測**(2026-11-23。測るときに、窓口が起動していなかった)。

## 測る方法

LocalLLMHarness を起動し(Unsloth Desktop を開いた状態で `uv run llh serve`)、`engine/` で次を実行する。

```powershell
cd engine
uv run python tools/measure_titles.py <データセットの動画のフォルダ> --chapters 5 --total 48
```

動画のフォルダは、`captions.*` と `chapters.json` があるもの(日本語の動画は `engine/dataset/GT5D1vSwq4Y` など)。字幕の本文は画面に出ず、題名の例・秒数・検証に落ちた回数だけが出る。

## 見る値と、止める基準(設計 §7 の 2)

| 値 | 基準 |
|---|---|
| 48 章の推定時間 | **20 分を超える**なら、方式を見直す(章数を絞る・1 回の呼び出しに複数章をまとめる) |
| 検証に落ちた率 | **50% を超える**なら、プロンプトか検証の規則(カタカナ・英字の一致)を見直す |
